# A structural write after a surprising bite

Freeze before exposure. No seed outside 952001..952032. Tune on 1..16, validate on 17..32 once. All seed offsets here are from 952000. No final. Population is a count of real offspring, not loss converted to flies.

Use 48 synchronous generations, 40 encounters each, and 48 founders. Every odor site is a row-column pair on a 4 by 4 grid. Its good polarity is a row sign times a column sign. A hidden axis starts at random. At a generation boundary it switches with probability .33. Each encounter independently flips one uniformly selected line of the current orientation with probability .12. Start from a uniform map. A fly chooses one of two opposite fruits of a random site, then observes its chosen polarity times the true site sign plus Gaussian noise (SD .75). The other fruit and actual nutritional return are unavailable to the learner. There is one bite per encounter. Ties use a fair coin. All newborns remain local. Each adult has stochastic-rounded `(0.5 + 3 * fraction nutritious) / (1 + adults / 32)` offspring, then dies. Census all generations 25..48, including zeros. All arms see the same interface, including the public generation boundary; only the diagnostic oracle gets the axis for setting L2's validation thresholds. Nothing receives the map.

L1 applies a fixed local correction. L2 accumulates corroborating prediction errors for a proposed row or column sign reversal. Crossing the line's threshold rewrites that whole line of L1 and clears incompatible evidence. The parameter of interest is which *hypotheses require more corroboration*, not a gain on the local update. Candidate biases are -4, -1, 0, 1, 4. Candidate local gains are .08, .25, .55 and evidence thresholds are .7, 1.5, 3. Lock local gain and threshold to the best constant L2. Select its bias separately for each true axis using the offspring censuses in that regime. This is hindsight across tuning trajectories. Rerun the resulting dynamic oracle policy end-to-end on holdout. No splicing in (c).

FIXED candidates: local exponential updates with and without parent weights, and a Kalman linear predictor using the true per-site correlation. Gains depend only on the input schedule for these fixed learners. Include a sitewise two-state Bayes as an extra conservative flat challenger. All arms have B=25 raw binary64 words across birth (16 local estimates, eight edit scores and one L3 bias for META3). A five-expert fixed-share acts with a mixture of L2 predictions, without writing back to any expert. The monolithic flat challenger filters the 128 distinct maps times two axes. Its within-life updates are exact given its newborn prior. At birth compare two compression methods from the same budget. No public or pooled fly state.

Decisions: (a) report both the actual constant L2 and the strongest flat member against FIXED; call a gain clear at >=1 fly and paired exact p<.01. (b) report hindsight minus the single best constant, half of its improvement over FIXED, and the same comparison charged against the stronger flat learner. Count positive surplus above .25 fly as margin. (c) use the **tuning-selected strongest eligible arm** for L2 in `2*ORACLE3 - 3*L2 + FIXED`, as well as all separate family winners. Positive held-out mean d4 triggers one already-specified learned run, even if it is noisy or (a,b) fail. The putative learned arm adjusts the validation bias only after a triggered L2 edit is subsequently tested on a *different* site on its line. Compare its updated and counterfactual unflipped forecast on that bite. Reward or penalize the axis according to the loss difference. No regime input; no selection among experts' outputs. SHAM uses a fair sign on the same write opportunities; no-write and mutation-only controls included if (c) passes. No gate adjustments. Pair by world, not fly, regime, or census; use exact one-sided sign-flip on integer census contrasts.
