# L4-D. Step size as the only write channel

Exploratory protocol, specified before running any ecological cell. One world. No tracked changes. Tuning uses all and only 3101..3116. Do not open 3117..3132 unless the tuning oracle passes. No world, endpoint, class, or grid rescue after looking.

## Garden

Four equally likely odor families in a well-mixed foraging culture. Each has two odor polarities. Two families have volatile nutritional sign (flip probability .065/tick) and reliable labels (error .04); the other two have stable sign (.0008) and unreliable labels (.32). Randomize the hidden two-two assignment per seed. Swap roles at geometric hazard 1/384 per tick. Switch roles before flipping signs. Starting signs and initial roles are exchangeable. Roles, signs, noise draws and prices never enter a non-oracle learner. All controllers have access to the model specification, but not its realization.

Each fly randomly encounters one family, polarity and price U in [0,1) per tick. It decides whether to ingest, then always receives one noisy nutritive taste (the realized food value, 0 or 1). Payout if accepted is value minus price; zero if declined. The price is visible to the common feeding rule only. For a true conditional probability q and prediction p this decision loses (q-p)^2/2 in expected gross intake relative to using q. Population-dependent metabolic cost produces competition; 60 founders, finite lifespan, a fixed birth threshold and a 400-fly safety cap. This is a different ecology from World4, not a patch to its movement or structural-search code. Keep the World4 endpoint: average of the 100 live colony counts at 10100,10200,...,20000. Secondary: late pre-taste squared error to the latent mean by role and actual feeding payoff, not a replacement primary.

## Controllers

One active feature per encounter. Let w predict signed canonical taste y in {-1,1}. Feeding reads (1+polarity*w)/2. All non-null updates are w <- w + alpha*(y-w), alpha in [1/128,1]. No controller can set a prediction at feeding time. NOREV never updates w. FIXED is the best scalar constant picked on tuning, not a deliberately bad constant. This is linear LMS, not logistic SGD, so the original coefficient 4 is not a baseline in these units. L1 weights start at zero at every birth.

IDBD updates log alpha by theta*(y-w)*h, clips the resulting rate, then updates h <- (1-alpha)*h + alpha*(y-w). Rate state passes to offspring; the weight-sensitivity trace restarts with the weights. Lock IDBD's starting alpha and theta on population. This is the matched substrate for META3 and EVO-R3. Other adaptive families and weaker arms can neither lower L2best nor replace the matched substrate.

At every real taste, compute low, center and high counterfactual next weights from the SAME pre-update w, alpha, trace and label, varying only theta over {center/span,center,center*span}. At the next encounter with that family, score the previous low-vs-high counterfactuals on the unseen canonical taste. The signed, discounted difference and discounted absolute difference, both with decay .9, give a normalized score. META3 chooses low or high theta by sign (center for zero). Scores inherit, unscored counterfactuals do not. No counterfactual environment step, extra label, cross-fly pooling or oracle feedback. RESET zeros scores only at birth. SHAM3 exactly averages the three possible *post-clip* rate writes on each encounter, independently of labels assigned to their identities; otherwise it executes the same calculations. EVO controls theta only at birth, inherited between births; include neutral E0, balanced standing variation over the three settings with mutation rates 0, .1 and .5. Matched P00 = FIXED, P10 = locked IDBD, P11 = META3, P01 = active shadow with the fixed rate used by L1. Also gate against the strongest unrestricted-by-family named challenger.

Challengers (highest population, ties by listing order):

- Scalar rates 1/128, 1/32, 1/8, 1/4, 1/2, 3/4, 1, plus static heterogeneous assignments of two odors each to 1/32 vs 3/4 or 1/8 vs 1 (all six assignments).
- IDBD starting at each of {1/32,1/4,1,best scalar}, crossed with theta {1/64,1/16,1/4,1,4}.
- One-hot AutoStep (elementwise normalizer plus stability cap), best scalar initial rate, meta-step {.005,.02,.08,.32}, time constant {100,10000}. RMS step on discounted squared gradient, scale {1/32,1/8,1/2}, decay {.875,.984375}.
- DIRECT reads exactly the same delayed normalized branch-loss score, its own h and its current error. Map the preference times the current direction of (y-w)*h to absolute low/high alpha, either hard or interpolated continuously in log-rate. Rate pairs {1/32,1/2}, {1/16,1}, {1/8,1}; spans {2,8,32}, on locked IDBD. Identical shadow probe budget as META3.
- BAYES-DIRECT: four posterior masses per odor (role x sign) inferred from experienced labels and inter-encounter times, not the true role or sign. Take the next-encounter posterior mean, and project it onto the reachable single alpha update. Timing multipliers {.5,1,2} apply to all hazards. It has fewer live state scalars per feature than META3, and is allowed to inherit the sufficient statistics. Neither arm reads other lineages. This named comparator is intentionally strong.

ORACLE3 knows current hidden state. It chooses whichever of the same three on-channel theta writes puts the resulting w closest to the expected sign-coded label at the *next encounter*, integrating over wait, regime transition, sign flips and observation noise. It does not read the next random draw. Lock span from {2,8,32} by tuning population. It is a decision oracle for one next taste, not an upper bound on all attainable lifetime populations. Also run an ungated full-channel diagnostic with the same knowledge but arbitrary allowed alpha. Baseline and role-specific error curves quantify, rather than assume, whether a constant rate suffices.

## Decision

Run challengers and oracles first, no META3 or holdout endpoints. Select the single best overall challenger across the full tuning bank, never per seed. Continue only if its gain over FIXED is positive, oracle d4 > 1.0 fly and exact upper-tail p < .05. Report p as descriptive after selection. Raw contrast integers 2*O-3*M+F, unit 1/200 fly; use signflip(ints,1) from docs/paper/stats.mjs. Ratio uses means of differences. Freeze the winning span independently of META3. Only on a pass, tune EVO variants on the same 16 seeds, freeze the best including E0, and run each locked held-out cell once. Never tune after held-out. Preserve the original control gates (1 fly over all three challengers, positive d4 and matched factorial, 11/16 factorial signs, positive lower rungs and RESET advantage, each exact p < .01). A held-out pass is advice to register, not a final L4 claim.

No universal hierarchy theorem is at issue. An unrestricted direct update can inline the joint-state transition exactly. A finite comparison can support only an advantage over the listed families. Do not exclude a direct rule merely because it beats META3 or claim an empirical optimum over all possible single-level learners.
